# **Far North District Council** Public Road Closures Feed

This repository is published by **Far North District Council** to support public access to road closure information.

It exists to provide a clear and accessible public information source that can be used in public-facing applications, maps, websites, and related information services.

## Publisher

**Organisation:** **Far North District Council**  
**Short Name:** FNDC  
**Country:** New Zealand

## Purpose

The purpose of this repository is to support public access to Far North District Council road closure information in a format suitable for public communication, display, and awareness.
